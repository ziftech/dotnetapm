# Screenshots (local only)

PNG captures under this folder are **gitignored** and are not published to GitHub.

Generate them locally with:

- `scripts/Capture-DemoScreenshots.py`
- `scripts/Capture-PerAppDemoScreenshots.py`
- `scripts/Capture-VbWaterfall.py`

Paths in `results/*.md` that mention `screenshots/*.png` refer to these local files.
